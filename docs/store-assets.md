# ストア掲載用アセットの準備手順

Chrome ウェブストアの掲載情報に必要な画像素材と、その撮り方をまとめます。

## 必要な素材

| 素材 | 寸法 | 必須 | 備考 |
| --- | --- | --- | --- |
| スクリーンショット | 1280×800（または 640×400） | 最低 1 枚・最大 5 枚 | 下記の「撮る画面」参照 |
| ストアアイコン | 128×128 | 必須 | `public/icons/icon128.png` が作成済み |
| プロモタイル（小） | 440×280 | 任意 | 未作成。必要なら別途用意する |

## 撮る画面

この拡張の実際の画面を、fixtures を使って撮影します（実サイトは使いません）。

1. **初期設定画面**（`onboarding.html`）— プリセットを選ぶところ
2. **ポップアップ**（`popup.html`）— 「このサイトでの結果」が表示されている状態
3. **ポップアップの詳細**（`popup.html`）— 「このサイトの設定」を開いて、サイトごとのトグルが見えている状態
4. **詳細設定**（`options.html`）
5. **fixture のバナーが消える様子**（`fixtures/custom-ja.html` など）— 同意画面が自動処理される前後

## 撮り方

1. `pnpm fixtures` を実行し、`dist/` と `fixtures/` を配信するローカルサーバ（ポート 4173）を起動する
2. ブラウザで `http://localhost:4173/popup.html` のように、対象のページを直接開く
3. ブラウザのウィンドウを 1280×800 にリサイズする
4. macOS の場合は `Cmd+Shift+4` の後にスペースキーを押すと、ウィンドウ単位でキャプチャできる

`chrome` API が無い環境でも各画面が表示できるようになっています（一部の操作は無効化されますが、見た目の確認・撮影は可能です。詳細は README および `docs/SPEC.md` を参照してください）。

## 注意

- スクリーンショットには fixtures（`fixtures/*.html`）や拡張自身の画面だけを使い、実サイトの内容や個人情報が写り込まないようにする
- 撮影後、意図せず写り込んだ情報（ブラウザのブックマークバーやタブ、他のウィンドウなど）が無いか確認する
