規約更新モーダル（class="consent-modal" だけ）

class に consent は含みますが Cookie 語はどこにも無いダイアログです。 consent ・ privacy は汎用の属性ヒントなので、 dialog / position と同じくテキストに Cookie 固有語が無ければ容器にしません。 容器にしてしまうと、accept モードで「同意する」を・reject モードで「同意しない」を 押してしまい、どちらも誤クリックになります。

reject / accept どちらでも何も起きず、モーダルがそのまま残るのが正解です。
